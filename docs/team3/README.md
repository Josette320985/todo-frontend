# Team 3 member reports

Each Team 3 member keeps one report in this folder, named
`p<N>-<topic>.md` (for example `p3-docker-nginx.md`). The challenge requires
every team to deliver the issues it found, fixed and left pending; these
reports are that list.

## Template

Copy this skeleton into your report:

```markdown
# P<N>: <block name>

Owner: P<N> - Branches: `p<N>/...` - Findings: SEG-xx, SEG-Hxx

## Summary

One paragraph on what the block covered.

## Findings

| ID | Title | Status | Pull request |
|---|---|---|---|
| SEG-Hxx | ... | Fixed / Documented / Pending | link |

## Changes

What changed in each finding, file by file, and why.

## Evidence

Commands that prove each acceptance criterion, with their output.

## Pending

What was left out, why, and who should pick it up.

## AI prompts used

Prompts given to AI tools for this block, written in English.
```
